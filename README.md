# Sozan Tutor OS — V1 Manual-First

تطبيق PWA لسوزان يربط **الوقت + الحصص + الدخل + المصروفات** بدون أي API ذكاء اصطناعي مدفوع.

## ما يعمل الآن

- جدول أسبوعي متكرر للحصص.
- اختيار الحصة وتعديل بياناتها ثم حفظ التعديل.
- توليد حصص اليوم تلقائيًا.
- تعليم الحصة: تمت / مدفوعة / ملغاة.
- حساب عمولة السنتر وصافي الحصة.
- إضافة حركة مالية يدويًا باختيارات واضحة: دخل/مصروف، شغل/شخصي، الفئة، المبلغ، التاريخ والملاحظة.
- اختيار أي حركة مالية يدوية وتعديلها ثم حفظها أو حذفها.
- الحركات المرتبطة بحصة تُدار من حالة الدفع في صفحة اليوم لمنع اختلاف الأرقام.
- Dashboard شهري: الدخل، مصروفات الشغل، المصروف الشخصي، المتبقي، المستحقات، والعائد الحقيقي لكل ساعة مع وقت الانتقال.
- تحليل أداء آخر 28 يومًا بقواعد حسابية محلية، بدون إرسال البيانات إلى OpenAI أو أي API مدفوع.
- تسجيل دخول بكود خاص + Cookie موقّع.
- PWA قابلة للإضافة للشاشة الرئيسية على iPhone/Android.

## التكلفة

النسخة الحالية لا تحتاج OpenAI API ولا أي خدمة AI مدفوعة. على حدود Cloudflare المجانية المناسبة لمستخدم واحد، يمكن أن تكون تكلفة التشغيل الشهرية صفرًا، باستثناء دومين اختياري إن أردت شراءه.

## التقنية

- Cloudflare Worker + Static Assets
- Cloudflare D1
- Vanilla HTML/CSS/JS
- لا يوجد OpenAI API في مسار الاستخدام الحالي

## تشغيل محلي

```bash
npm install
cp .dev.vars.example .dev.vars
npm run db:migrate:local
npm run dev
```

## نشر Cloudflare

```bash
npm install
npx wrangler login
npm run deploy
npm run db:migrate:remote
npx wrangler secret put APP_PASSCODE
npx wrangler secret put SESSION_SECRET
```

- `APP_PASSCODE`: رمز دخول لسوزان.
- `SESSION_SECRET`: نص عشوائي طويل، يفضل 32+ حرفًا.

## طريقة الاستخدام اليومية

1. في **الجدول**: اختاري/أضيفي الحصص الثابتة. يمكن تعديل أي حصة لاحقًا وحفظها.
2. في **اليوم**: اضغطي تمت، تم الدفع، أو ألغيت.
3. في **الفلوس**: أضيفي أي مصروف أو دخل غير مرتبط تلقائيًا بحصة. يمكن تعديل أو حذف الحركة لاحقًا.
4. في **التحليل**: راجعي توصيات مبنية على الأرقام الفعلية لآخر 28 يومًا.

## ملاحظات

- تعديل الحصة المتكررة يحدّث السعر للحصص المستقبلية المجدولة غير المدفوعة.
- الدخل المرتبط بحصة مدفوعة يُنشأ تلقائيًا، لذلك لا نسمح بتعديله كحركة منفصلة حتى لا تتكرر أو تختلف الأرقام.
- هذه أداة تنظيم وإدارة وليست برنامج محاسبة ضريبي رسمي.
